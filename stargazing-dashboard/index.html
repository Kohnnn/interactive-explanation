Sky legend

Read the chart by layer, not decoration.

  • Stars: fixed point sources sized by relative magnitude.
  • Planets: brighter moving markers tied to the current clock.
  • Constellation lines: optional bearings for orientation.
  • Meteor radiants: shower origins shown when a stream is active.
  • Horizon and grid: altitude and azimuth guides for telescope aiming.

Focus the canvas, then use arrow keys to aim. Drag to pan the sky, adjust the time scrub for tonight's transit, and use the layer controls to reduce clutter before selecting a target.
