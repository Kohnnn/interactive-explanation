No Route is left without a target. The literal candidate contains four cycles:

1. **Primary collection return:** routes that conclude a primary, systems, mechanical, astronomy, or blockchain arc return to `primary-interactive-hub`; that hub restarts at `trust`, its documented first route. This is a curated collection loop, not a self-link.
2. **Music return:** the candidate reaches `musicmap` from `ableton-learning-synths-recipes`, then returns to `music-interactive-hub`, which restarts at `teoria-interval-ear-training`. This structure conflicts with the final edge of the published five-stop Guided Path and remains unresolved.
3. **Machine-learning return:** `double-descent2` returns to `decision-tree`, starting a concrete-model pass after the advanced complexity pair. The explicit `decision-tree` → `random-forest` companion handoff remains intact.
4. **Engineering loop:** `curves-and-surfaces` → `image-kernels` → `alpha-compositing` → `color-spaces` → `lights-and-shadows` → `curves-and-surfaces`. The original research did not document this loop as deliberate, so the Suggested Next Route contract must confirm or remove it.
