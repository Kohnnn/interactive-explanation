Source snapshot

This route does not vendor a published external article. It is a local original build created for the interactive-explanation collection and written specifically around modern Formula 1 systems.

  • The public route uses neutral provenance handling because there is no single upstream article to reference.
  • The shell reuses the Engineering Sandbox longform family so the route gets the shared hero, story rail, and mobile chapter navigation.
  • The body content, scenes, and explanatory copy are original local assets.

Asset handoff

  • formula-1-racing/index.html owns the route shell, longform body, and scene markup.
  • formula-1-racing/css/f1.css provides the Formula 1-specific visual language and scene styling.
  • formula-1-racing/js/f1.js drives the hotspot map, airflow, floor, power-unit, tyre, braking, track, and setup interactions.
  • shared/engineering-sandbox.css and shared/engineering-sandbox.js provide the shared shell behavior, generated rail, and hero framing.

Known deviations

  • This route is intentionally original, so the docs track implementation parity against the local design spec rather than an upstream replica.
  • The current build is phase 1: it ships the longform shell and the first full set of teaching scenes, but later phases may deepen each subsystem with richer diagrams or more exact simulation models.
  • Formulas and scene readouts are simplified explanatory models, not an attempt at regulation-grade or telemetry-grade simulation fidelity.

Validation guidance

  • Keep the route self-contained and subpath-safe; all assets should remain local to formula-1-racing/ or the shared shell.
  • Preserve generated chapter behavior by keeping major sections anchored with top-level h1 ids.
  • Run both node interactive-explanation/tools/check-public-surface.mjs and node interactive-explanation/tools/smoke-bundle.mjs after edits.
