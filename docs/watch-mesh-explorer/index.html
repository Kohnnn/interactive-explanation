Inside a Mechanical Watch

Local route /interactive-explanation/watch-mesh-explorer/ turns the ETA 2824-2 mesh archive into ten causal lessons with the complete workbench available as a secondary tool.

Design intent

The route is an original guided explanation, not an embedded copy of the archived watch renderer. Each step pairs one problem with one mechanism and one visible result on an ivory drawing plane with restrained materials, authored framing, and one active-state color.

Semantic model

Seventy-one meaningful assemblies provide names, roles, systems, mounting positions, explode vectors, and animation labels. Sixteen pivot-sensitive source meshes preserve archived local offsets, flips, and ZYX rotation composition after per-source centering. The assemblies reference the 85 physical mesh templates only when source geometry is needed; digits, cutaway templates, and reference shapes are not presented as installed components.

Guided lessons

Ten ordered lessons isolate Power, Gear Train, Escapement, Balance, Mainplate, Click, Motion Works, Keyless Works, Automatic Winding, and Physical Scale. Previous and next controls update the causal explanation, focused camera, active parts, register, and selected component together.

Component inspection

Canvas picking and the searchable register select the same assembly. Guided mode limits both surfaces to the current module; the inspector reports role, lesson, service stage, mounting direction, source templates, triangle count, and actionable neighbors. Reset view restores authored framing.

Runtime handoff

Route-local index.html, css/explorer.css, js/explorer.js, and js/model-table.js own the experience. Three.js and OrbitControls are reused from the sibling route; no new dependency or duplicate geometry asset is introduced.

Validation guidance

Run node --check watch-mesh-explorer/js/explorer.js, node tools/check-public-surface.mjs ., and node tools/smoke-bundle.mjs . --route watch-mesh-explorer. Browser checks should verify ten lessons, lesson-to-part isolation, Previous and Next progression, 71 complete-atlas components, all secondary modes, camera reset, paused render quiescence, footer mounting, and no overflow.
